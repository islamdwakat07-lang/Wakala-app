# مولّد وكالة خصوصية — تطبيق أندرويد (Kotlin + Jetpack Compose)

تطبيق أندرويد حقيقي (Kotlin + Jetpack Compose) يولّد وكالة خصوصية بنفس نص وشكل
قالب مكتب المحامي عبدالله دويكات، مع تعبئة الحقول المتغيرة كتابةً أو صوتياً،
وحفظ/مشاركة النتيجة كملف PDF مباشرة من الهاتف — كل ذلك بدون إنترنت.

## المتطلبات
- Android Studio (إصدار Iguana 2023.2.1 أو أحدث يُفضّل).
- جهاز أو محاكي يعمل بأندرويد 7.0 (API 24) فأعلى.
- اتصال إنترنت **لمرة واحدة فقط** عند أول فتح للمشروع، لتحميل Gradle وتبعياته
  (بعدها لا يحتاج التطبيق نفسه أي إنترنت لتوليد أو حفظ أو مشاركة الوكالة).

## الطريقة الأسهل: بناء APK تلقائياً عبر GitHub (بدون تثبيت أي برنامج)

المشروع يحتوي بالفعل على ملف `.github/workflows/build-apk.yml` يجعل خوادم GitHub
تبني لك ملف APK تلقائياً بمجرد رفع المشروع، وتضعه في صفحة **Releases** برابط ثابت
تفتحه من متصفح هاتفك مباشرة وتنزّله وتثبّته — بدون أي جهاز كمبيوتر أو برنامج.

1. أنشئ حساباً مجانياً على [github.com](https://github.com) إن لم يكن عندك واحد.
2. من الصفحة الرئيسية اضغط **New** لإنشاء مستودع (Repository) جديد، اختر له اسماً
   (مثلاً `wakala-app`)، اجعله **Public**، ولا تُفعّل خيار إضافة README (موجود مسبقاً
   ضمن المشروع). ثم اضغط **Create repository**.
3. ارفع ملفات المشروع: في صفحة المستودع الفارغة اضغط على رابط
   **uploading an existing file**، ثم اسحب مجلد `WakalaGenerator` بالكامل (بعد فك
   ضغطه) وأفلته داخل صفحة الرفع (متصفح Chrome على الكمبيوتر يدعم سحب المجلدات
   كاملة بهيكلها). انتظر انتهاء الرفع ثم اضغط **Commit changes**.
4. افتح تبويب **Actions** أعلى صفحة المستودع — ستجد أن عملية البناء "Build APK"
   بدأت تلقائياً (دائرة صفراء دوّارة). انتظر 3-5 دقائق حتى تتحول إلى علامة ✅ خضراء.
5. من الصفحة الرئيسية للمستودع، ابحث في الشريط الجانبي الأيمن عن **Releases** واضغط
   عليها (أو افتح مباشرة: `https://github.com/USERNAME/REPO/releases`).
6. ستجد إصدار باسم "أحدث نسخة APK" ومرفق به ملف `app-debug.apk` — افتح هذا الرابط
   من متصفح هاتفك مباشرة واضغط على اسم الملف لتنزيله.
7. بعد التنزيل، افتح الملف من إشعارات التنزيل أو تطبيق الملفات لتثبيته. إذا طلب
   أندرويد إذن "تثبيت من مصادر غير معروفة" فعّله لهذا التطبيق (المتصفح أو الملفات)
   مرة واحدة فقط، ثم أكمل التثبيت.

بعد ذلك، أي تعديل تريده لاحقاً على المشروع ثم رفعه (Commit) لنفس المستودع سيُبني
تلقائياً من جديد ويحدّث نفس رابط "أحدث نسخة APK" في Releases.

---

## الطريقة اليدوية: عبر Android Studio على جهاز كمبيوتر

1. افتح Android Studio ← **Open** ← اختر مجلد `WakalaGenerator` هذا بالكامل.
2. ملف Gradle Wrapper (`gradlew`, `gradlew.bat`, `gradle-wrapper.jar`) مرفق بالفعل
   ضمن المشروع، لذلك Android Studio سيتعرف عليه تلقائياً بدون أي خطوة إضافية.
3. انتظر حتى ينتهي **Gradle Sync** (شريط التقدّم أسفل النافذة).
4. لتشغيله مباشرة على هاتفك: وصّل الهاتف بكابل USB وفعّل **خيارات المطوّر / تصحيح USB**،
   ثم اضغط زر **Run ▶** في Android Studio.
5. لبناء ملف APK لتثبيته يدوياً: من القائمة العلوية
   **Build ← Build Bundle(s) / APK(s) ← Build APK(s)**،
   وبعد الانتهاء اضغط الرابط الذي يظهر أسفل النافذة (**locate**) لفتح مكان الملف:
   `app/build/outputs/apk/debug/app-debug.apk`
   انسخه إلى هاتفك وثبّته (فعّل "السماح بالتثبيت من مصادر غير معروفة" إذا طُلب ذلك).

## هيكل المشروع
```
app/src/main/java/com/wakala/generator/
├── MainActivity.kt     # واجهة Compose بالكامل (الحقول، الميكروفون، المعاينة، الأزرار)
├── WakalaText.kt        # النص الثابت للوكالة + منطق تبديل صيغة المفرد/المثنى
├── PdfGenerator.kt       # توليد ملف PDF (صفحة A4) عبر android.graphics.pdf.PdfDocument
└── Utils.kt              # التعرف على الصوت، المشاركة، الحفظ في مجلد التنزيلات
```

## المزايا
- **حقول التعبئة**: اسم الموكل ورقم هويته، خيار إضافة موكل ثانٍ باسمه وهويته،
  رقم الحوض، رقم القطعة، اسم البلد، اسم الموقع/دوائر التسجيل، اسم القضاء، والتاريخ.
- **إدخال صوتي** 🎤 بجانب كل حقل، عبر خدمة التعرف على الصوت المدمجة في أندرويد
  (تُفعّل تلقائياً بصيغة "تفضيل عدم الاتصال" `EXTRA_PREFER_OFFLINE`؛ ستعمل بدون
  إنترنت فعلياً فقط إذا كانت حزمة اللغة العربية للتعرف الصوتي دون اتصال منزّلة على
  الجهاز من: الإعدادات ← النظام ← اللغات ← التعرف الصوتي على الجهاز).
- **معاينة حيّة** لنص الوكالة كاملاً مع نفس التسطير الموجود في الورقة الأصلية.
- **توليد PDF فعلي** بحجم A4 مطابق لشكل القالب (ترويسة، خط فاصل، نص مبرّر، تسطير،
  وتذييل بتاريخ التحرير وخانة الموكل يمين الصفحة وتصديق المحامي يسارها) بدون أي
  مكتبات خارجية — فقط Android SDK القياسي، لذلك يعمل بدون إنترنت دائماً.
- **مشاركة PDF** مباشرة عبر قائمة المشاركة في أندرويد (واتساب، تيليجرام، البريد...).
- **حفظ PDF** في مجلد "التنزيلات" العام على الهاتف.

## ملاحظات مهمة
- التطبيق **لا يطلب إذن الإنترنت إطلاقاً** في ملف AndroidManifest؛ كل شيء عدا
  الإدخال الصوتي (الذي يعتمد على خدمة النظام) يعمل محلياً بالكامل.
- الأذونات المطلوبة وقت التشغيل: **المايكروفون** (فقط عند الضغط على أيقونة 🎤)،
  و**التخزين** (فقط على أندرويد 9 فأقل عند الضغط على "حفظ PDF").
- الاسم الحزمة الافتراضي `com.wakala.generator` — يمكنك تغييره من
  `app/build.gradle.kts` (`applicationId` و`namespace`) وإعادة الـ Sync قبل النشر
  على المتجر إذا رغبت.
- لتغيير بيانات المحامي الثابتة (الاسم، رقم الهوية، الهاتف) عدّل النصوص المباشرة
  في `WakalaText.kt` و`PdfGenerator.kt`.
